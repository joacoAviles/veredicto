# Práctica agentes

Carpeta de práctica para aprender el flujo Veredicto → Hermes. Aquí no hay nada real.

## Reglas
- Trabaja solo dentro de esta carpeta. Los archivos que crees van en `./salidas/`.
- Haz exactamente lo que dice la tarea. Usa comandos simples (`mkdir -p`, `touch`, `mv`, `ls`).
- Al terminar, revisa con `ls -R salidas` que quedó como pide el «criterio de listo» y responde con las rutas.
- Si algo no se puede, responde «BLOQUEADA: …» con lo que falta.
